**PERCEPTRON SIMULATOR:**

This artificial neuron works somehow. 

The weights define the importance of the corresponding input. 

This project is still work in progress. 

**USAGE:**

To run this program, execute the file "main.py".

This can be done via a terminal or the command line.

*Training Data*:

To insert custom training data, write the data into "learning_data.csv".

The last column is the label for the inputs.

Make sure each input is seperated by a ";" and different data sets are in different lines.

When training be sure to configure as many weights as the training data has inputs.

**Troubelshooting:**

Nothing happening on opening: Make sure that you are opening the right file and that you have python installed.

Not being able to train or classify: Make sure all files are in the same directory.
